What this repository is

A repository-shaped documentation source pack.

agentskills-docs turns the published AgentSkills.io documentation into a clean repository that can be cloned, searched, read, and supplied to AI collaborators without changing the underlying guidance.

The mirrored documents are preservation-bound reference material. The repository adds navigation and provenance around them, not a competing version of the Agent Skills standard.

Not the official development repository. The Agent Skills standard is developed upstream in agentskills/agentskills. This project mirrors the published documentation for knowledge access and collaboration.

Why it exists

Keep one trustworthy source available across human and agent workflows.

AgentSkills.io is written for human developers. This repository preserves that same guidance in a form that can also be handed directly to AI collaborators working on Agent Skills.

Browse it

Humans get a simple index, readable Markdown, source links, and clear provenance.

Clone it

The source pack can live locally as part of a larger knowledge base and remain useful without a website workflow.

Give it to agents

AI collaborators can follow the repository’s routing and authority rules instead of relying on partial recollection or ad hoc summaries.

How the mirror preserves source integrity

The repository uses canonical AgentSkills.io Markdown rather than rendered HTML. The local files add a # Source: provenance header and remove the non-substantive Mintlify AI-navigation banner. The manifest records that substantive content is not rewritten.

The mirrored corpus changes only after a verified official documentation change. The repository’s synchronization workflow checks upstream and prepares changes for human review rather than silently merging into main.

How the repository is organized for humans and agents

00-index.md is the human-readable document map. AGENTS.md is the agent navigation and authority contract. sources.json is the provenance manifest. The nine mirrored Markdown files remain the preserved source corpus.

This GitHub Pages site is only the human-facing presentation layer. It is intentionally kept separate from the knowledge-source content on main.

Preservation & freshness

Preserve the mirror. Review the change.

Mirrored documentation is expected to remain unchanged until the corresponding official AgentSkills.io documentation changes. When upstream changes are detected, the repository is designed to prepare a reviewable update rather than mutate the canonical branch silently.
